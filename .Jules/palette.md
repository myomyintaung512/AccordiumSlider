## 2026-03-31 - Synchronizing Keyboard Focus and Mouse Hover in Shared Preview Galleries
**Learning:** In shared-preview galleries (where multiple items trigger a single layout expansion or preview block), managing active states using standard `:hover` and `:focus` independently can lead to visual flickering or premature closure during transitions. Explicit synchronization using dual `hovered` and `focused` state flags in JavaScript combined with event delegation for nested interactive elements ensures seamless transitions.
**Action:** Use unified event listeners for `mouseenter focusin` and `mouseleave focusout` to track individual item states, and coordinate row-level transitions using a centralized debounced helper to verify if any sibling items in the same row are currently active before collapsing the preview.
