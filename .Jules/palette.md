## 2026-11-10 - Keyboard accessibility and ARIA for custom jQuery accordion sliders
**Learning:** Custom interactive accordion gallery boxes built out of generic `<div>` elements are inaccessible to keyboard and screen reader users without explicit keyboard focus management (`tabindex="0"`, `role="button"`), Enter/Space keydown activation, and `focusin`/`focusout` listeners synchronized with mouse interactions. Moreover, child anchor tags inside clickable boxes can be accidentally triggered or intercepted unless checked with `$(e.target).is("a")`.
**Action:** When modernizing legacy DOM-manipulation plugins, bind synchronized pointer/focus event pairs (`mouseenter focusin` and `mouseleave focusout`), provide accessible fallback labels with index, and prevent event collision with nested interactive anchors.
