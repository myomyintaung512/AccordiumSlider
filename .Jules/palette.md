## 2026-08-10 - Coordinating State and Keyboard Focus in Accordion Galleries
**Learning:** Transforming hover-only image galleries into fully accessible keyboard-navigable components requires coordinating multi-state interaction. Simply binding `focusin` and `focusout` leads to severe UI flickering and premature collapse because focus moves between the parent interactive `.box` container and nested anchor elements. Additionally, in multi-row grids, moving focus to a different row must cleanly deactivate previous rows without closing them prematurely while the user is actively tabbing.
**Action:** Use decoupled jQuery state flags (`h` for hover, `f` for focus) on elements combined with a micro-timeout debouncer (e.g., 10ms). Before closing or transitioning row-preview components, verify if ANY sibling box in the active row remains hovered or focused. This ensures smooth visual transitions, prevents flickering, and coordinates sequential tab order flawlessly across grid rows.
