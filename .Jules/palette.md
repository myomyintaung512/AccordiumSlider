## 2026-03-31 - [Keyboard Accessibility and ARIA Attributes in Legacy jQuery Accordions]
**Learning:** Legacy hover-based gallery containers lack semantic keyboard markers and fail to reveal interactive preview overlays when navigating via Tab. Simply binding `focus` listeners can lead to layout jitter or code bloat if state-management logic is duplicated. Extracting the hover state transitions into unified helper functions (`showBox`/`hideBox`) and using chained jQuery handlers (`mouseenter focusin` / `mouseleave focusout`) keeps the patch extremely clean, concise, and under the 50-line boundary limit while achieving perfect keyboard and screen-reader parity.
**Action:** Always refactor inline visual state mutations into separate, descriptive helper functions so that mouse hover and keyboard focus events can easily share the same logic without cluttering the event loop or exceeding file modification line budgets.
