## 2026-03-30 - Keyboard Accessibility & Focus Preview Expansion in jQuery Galleries
**Learning:** Legacy jQuery accordion/slider galleries that rely solely on `.hover()` event handlers exclude keyboard-only and screen reader users from accessing image previews and activating gallery links. Chaining `.on('mouseenter focusin', ...)` and `.on('mouseleave focusout', ...)` while setting `tabindex="0"`, `role="link"`, and cleaned `aria-label` attributes ensures seamless keyboard accessibility and synchronized visual feedback.
**Action:** When updating legacy interactive container components, add ARIA attributes during initialization and pair hover handlers with `focusin`/`focusout` and `keydown` listeners (Enter/Space) to guarantee full keyboard accessibility without breaking mouse interactions.
