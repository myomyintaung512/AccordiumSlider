## 2026-03-24 - Syncing Hover and Focus States in Shared-Preview Galleries
**Learning:** In shared-preview accordion galleries (like mmDeveloperSlider), utilizing simple hover handlers ignores keyboard navigation, making the components completely inaccessible to screen readers and keyboard-only users. Furthermore, trying to sync mouse and keyboard states by relying only on standard focusout/mouseleave events can lead to premature deactivation and flickering because of rapid transition between focus/hover transitions across siblings.
**Action:** Always map focus states in tandem with hover states, using separate tracking flags (e.g., `hovered` and `focused`) on elements to coordinate active UI state transitions smoothly. Introduce a slight debounce/micro-timeout when checking whether any sibling element remains active before collapsing shared panels.
