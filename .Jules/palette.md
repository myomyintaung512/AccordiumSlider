## 2026-03-30 - Keyboard accessibility & focus synchronization for legacy accordion sliders
**Learning:** In legacy jQuery accordion sliders that rely on container hover to expand previews and navigate via `url` attributes, keyboard users cannot discover or interact with the items. Adding `tabindex="0"`, `role="link"`, and syncing `mouseenter focusin` / `mouseleave focusout` provides full keyboard parity. However, when containers have nested links, using `e.preventDefault()` on Space and checking `if ($(e.target).is('a')) return;` is essential to prevent conflicting actions and browser scrolling.
**Action:** When modernizing click/hover container galleries, always wire both mouse and focus events to unified activate/deactivate routines and guard nested focusable interactive elements from double activation.
