## 2026-03-31 - Keyboard Focus and Hover Coordination in jQuery Galleries
**Learning:** In legacy jQuery galleries like mmDeveloperSlider, combining keyboard accessibility with mouse hovers requires explicit state tracking. Relying solely on 'mouseenter/mouseleave' and 'focusin/focusout' without coordination causes UI flickering and premature closing of shared expansion areas during transitions. Using separate '.data("hovered")' and '.data("focused")' flags, combined with a 10ms micro-timeout debounce, is extremely robust and ensures smooth UI transitions.
**Action:** Always coordinate keyboard focus and mouse hover states using explicit, separate data attributes and a short debouncing mechanism when implementing keyboard navigation in interactive grid/gallery containers.
