## 2025-05-14 - Retrofitting Accessibility in Legacy jQuery Galleries
**Learning:** Legacy components often use `hover` events for critical UI state changes (like expanding previews), which excludes keyboard users. Retrofitting accessibility requires refactoring this logic into shared functions that can be triggered by both `mouseenter` and `focusin`. Additionally, when interactive containers have nested links, using `focusin` and `focusout` on the parent is more robust than `focus` and `blur` for maintaining state as the user tabs through internal content.
**Action:** Consolidate UI animation logic into internal `activate` and `deactivate` functions. Use `focusin` and `focusout` for event delegation on shared interactive containers to ensure consistent behavior across mouse and keyboard interactions.
