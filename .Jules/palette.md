## 2026-11-08 - Synchronizing Keyboard Focus and Mouse Hover in Legacy jQuery Accordions
**Learning:** In legacy jQuery accordion galleries where expanding preview containers are shared across items in a row, using mouse-only hover events leaves the gallery completely inaccessible to keyboard and screen reader users. Simply listening to `focusin` and `focusout` can cause rapid animation flickering and premature closure when navigating between sibling items or interacting with internal child elements.
**Action:** Decouple state management using dual `hovered` and `focused` data flags on each item, combined with a 10ms micro-timeout to check sibling activation before collapsing row previews. Always prevent default scrolling on Spacebar (`e.preventDefault()`) and safeguard nested interactive elements (such as `<a>` links) from triggering parent container actions.
