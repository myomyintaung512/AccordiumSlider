## 2026-03-01 - Synchronizing Keyboard Focus and Mouse Hover in Legacy Accordions
**Learning:** In highly interactive custom JavaScript/jQuery accordion galleries, simple mouse-hover event handlers are completely inaccessible to screen readers and keyboard users. Chaining `.on('mouseenter focusin', ...)` and `.on('mouseleave focusout', ...)` creates a beautifully synchronized user experience, but can trigger animation flickering and race conditions during focus transitions. Additionally, nested focusable elements (like `<a>` tags) within interactive containers affect sequential tab order and must not be overridden by the container's navigation triggers.
**Action:** Use separate jQuery `.data('hovered')` and `.data('focused')` flags combined with a 10ms micro-timeout debouncer to ensure smooth, non-flickering visual state transitions. Explicitly allow nested link interactions using `if ($(e.target).is('a')) return;` in keydown/click handlers, and account for intermediate sequential focus steps in verification scripts.
