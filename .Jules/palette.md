## 2026-05-08 - Keyboard Accessibility for Legacy jQuery Gallery
**Learning:** Legacy galleries built with `div` elements and `click` handlers are completely inaccessible to keyboard users and screen readers. Adding `tabindex="0"` and `role="link"` is the first step, but the visual feedback (animations) must also be synchronized between hover and focus states to ensure a consistent experience. Using jQuery `.data()` to track focus state prevents "flickering" or premature collapse when mouse and keyboard interactions overlap.
**Action:** Always check if interactive `div` elements have `tabindex` and `role`. When adding focus support to a hover-based UI, refactor animations into shared functions and use state flags to coordinate between `mouseenter`/`focusin` and `mouseleave`/`focusout`.
