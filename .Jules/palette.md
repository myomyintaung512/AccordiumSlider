## 2026-08-02 - Unifying Mouse Hover and Keyboard Focus in Legacy jQuery Gallery Components
**Learning:** In legacy jQuery-based interactive galleries, implementing keyboard navigation alongside mouse hover interactions can introduce race conditions and UI flickering during quick state transitions. Using explicit `.data('hovered')` and `.data('focused')` flags coordinates interaction sources much more reliably than depending on event bubbling or `relatedTarget`. Furthermore, in clickable wrapper boxes, checking for nested link targets (e.g., `$(e.target).is('a')`) is crucial to prevent parent navigation handlers from breaking semantic, nested anchor tag links.
**Action:** Always coordinate mouse hover and keyboard focus states using separate custom jQuery `.data()` flags combined with a 10ms debouncing micro-timeout. Before executing parent click/keydown container navigation, check `$(e.target).is('a')` and bypass the action if the target is a nested link. Only bind mouse interaction listeners to non-focusable injected preview containers to preserve clear tab ordering.
