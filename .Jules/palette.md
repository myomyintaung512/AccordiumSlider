## 2026-08-11 - Coordinated Keyboard Focus in Legacy jQuery Accordion Galleries
**Learning:** In legacy jQuery accordion galleries where items expand dynamically, simple focus event listeners can clash with hover states, causing visual flickering. Using synchronized `.data('hovered')` and `.data('focused')` flags with a minor deactivation timeout (10ms) creates a highly resilient interaction model that bridges keyboard and mouse contexts seamlessly. Furthermore, utilizing event bubbling on nested interactive elements (like `<a>` links inside focused `.box` containers) prevents container-level click navigation from overriding link targets.
**Action:** Next time, implement structured hover/focus coordination with small debounced timeout checks and explicit event object (`e`) parameter checking rather than separate conflicting listeners.
